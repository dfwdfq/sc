#+title: sc
X11 screenshot tool for tiling window managers

* Dependencies
- Raylib
- Raygui /(included in repo)/
- Xlib
- Cmake
- picom /(should be running in background)/

* How to build
#+BEGIN_VERSE
If *Xlib* and *Raylib* are installed, then it's simple:
#+END_VERSE
#+BEGIN_SRC bash
  cd sc_source/
  mkdir build && cd build
  cmake -S .. -B
  make
#+END_SRC
